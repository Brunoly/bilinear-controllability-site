Controllability of bilinear systems

This page contains work in progress studying the controllability of bilinear systems.

Main results: Controllability of continuous-time bilinear systems is undecidable.

The set of controllable discrete-time bilinear plants is nonsemialgebraic.

Continuous-time

What is a continuous-time bilinear system?

x˙(t) =(A+ ∑i=1m ui(t) Bi )x(t)

where A, B1, …, Bm ∈ ℝn×n, x(t) ∈ ℝn, and ui(t) ∈ ℝ.

The system is globally controllable if every nonzero initial state can be steered exactly to every nonzero target state in finite time using unrestricted controls.

Current results

We prove the impossibility of a general algorithm capable of determining, given rational matrices A, B1, …, Bm, whether the system is globally controllable.

Proof of undecidability of continuous-time bilinear controllability (GitHub)

Discrete-time

What is a discrete-time bilinear system?

xk+1 = (A + uk B)xk

where A, B ∈ ℝ2×2, xk ∈ ℝ2, and uk ∈ ℝ.

We use the following definition of controllability:

A plant is controllable if every nonzero state in ℝ2 can be steered to every nonzero target state in a positive finite number of steps.

Current results

Using GPT Astra, we found that for discrete-time bilinear systems in dimension 2, there is no fixed finite combination of polynomial equalities and inequalities in the entries of A,B that can exactly characterize controllability. In other words, the set of controllable pairs is nonsemialgebraic.

Proof of nonsemialgebraicity of discrete-time bilinear controllability (GitHub)
